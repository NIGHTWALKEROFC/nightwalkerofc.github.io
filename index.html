Who's behind the terminal

Self-taught, phone-only, still shipping.

Since 4th standard, the goal hasn't changed: become an ethical hacker. There was never a laptop to make that easier — just curiosity, patience, and whatever an unrooted Android phone would allow.

That constraint became a habit. I spend hours at a stretch going deep on one topic before moving to the next — security tooling, Android internals, Flutter, Kotlin — learning by doing rather than by having the "right" setup.

Today that same phone runs security tools, drives GitHub's web editor, and triggers Codemagic builds — the full pipeline for real, working apps, end to end.
